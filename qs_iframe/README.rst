# MindMap \& Excalidraw

## Overview

This module provides powerful embedding and editing capabilities inside the Odoo backend, including custom webpage embedding, online mind map editing and Excalidraw whiteboard drawing\. All edited data can be fully persisted in the Odoo database for permanent storage\.

## Core Features

### 1\. Backend Webpage Embedding

Provides universal webpage embedding capability within the Odoo backend\. Administrators can pre\-configure and manage multiple URL lists\. Users can quickly switch different embedded pages through the dropdown menu, and support one\-click page refresh operation\.

### 2\. Online Mind Map Editor

Built\-in professional mind map module, supports full online mind map editing\. All mind map structure data, configuration parameters and language settings are stored persistently in the Odoo database, ensuring data will not be lost after page refresh or re\-opening\.

### 3\. Excalidraw Whiteboard Editor

Native embedded Excalidraw canvas, supports free hand\-drawing, graphic arrangement and element editing\. The module adopts delayed automatic saving strategy, all canvas element changes will be automatically saved to the Odoo database, realizing real\-time data persistence\.

### 4\. One\-Click Independent Editing \& Bridge Communication

Users can open dedicated mind map and whiteboard independent editing views with one click through form buttons\. The frontend editing page and Odoo backend complete data interaction through a stable bridge communication mechanism, realizing seamless data reading and saving\.

## Highlights

- Fully embedded in Odoo backend, no external software required

- All editing data persisted in Odoo database, safe and controllable

- Auto\-delay save for whiteboard to avoid frequent database requests

- Unified URL management, convenient for internal system integration

- Stable front\-end and back\-end bridge data communication

## Usage

1. Administrators configure commonly used webpage URLs in the background for embedded access

2. Open the mind map or whiteboard editing interface through document form buttons

3. Edit mind map nodes or whiteboard graphics freely

4. The system automatically saves changes to the database, supporting persistent reuse
